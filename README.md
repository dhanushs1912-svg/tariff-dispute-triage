# Electricity Tariff and Billing Dispute Triage Service

Mini Project 11 — UE24AM342AA5 ML System Design and AgentOps (Jackfruit, Level 3)

A multi-agent service that takes a consumer's billing dispute, validates it, works out the correct tariff category from the KERC (Karnataka) tariff order and supply code, and routes the case to *bill-stands-with-reason*, *revision-recommended* or *site-inspection-required* with clause-level citations, or escalates to a grievance officer when the provisions do not settle it. It never revises a bill.
